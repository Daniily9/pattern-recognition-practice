### Основні результати

| Модель | Accuracy test | F1-macro test |
| :--- | :---: | :---: |
| **DummyClassifier** | 0.333 | 0.167 |
| **DecisionTree (max_depth=3)** | 0.933 | 0.933 |
| **DecisionTree (max_depth=None)** | 0.933 | 0.933 |

*Примітка: Дерево без обмеження глибини показало точність 1.0 на train, але розрив із test збільшився, що наочно демонструє ефект перенавчання (overfitting).*
