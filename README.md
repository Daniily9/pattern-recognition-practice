### 🫀 Практичні роботи 4–7: Мініпроєкт «Порівняння класичних моделей класифікації»
**Тема:** Побудова відтворюваного конвеєра машинного навчання, налаштування гіперпараметрів та оцінювання моделей бінарної класифікації за умов закритої тестової вибірки.

#### 📌 Постановка задачі
Необхідно за клінічними характеристиками пацієнта визначити наявність ознак серцевого захворювання. Задача є бінарною класифікацією. 
* **Цільова змінна (`target`):** `0` — ознаки відсутні, `1` — ознаки наявні (позитивний клас).
* **Основна метрика:** F1-score, **Додаткова метрика:** ROC AUC.
* **Дані:** Heart Disease Dataset (UCI Repository), 297 об'єктів, 13 ознак.

#### ⚙️ Preprocessing та Експериментальна методика
* Датасет розділено на Train (80%) та Test (20%) зі стратифікацією. Тестова вибірка була повністю закрита до фінального кроку.
* На навчальних даних створено єдину схему 5-кратної крос-валідації `StratifiedKFold` (random_state=42).
* Усі перетворення об'єднано в `ColumnTransformer` всередині `Pipeline` для уникнення витоку інформації (data leakage):
  * **Числові ознаки** (`age`, `trestbps`, `chol`, `thalach`, `oldpeak`): медіанна імпутація + `StandardScaler`/`MinMaxScaler`.
  * **Категоріальні ознаки**: імпутація модою + `OneHotEncoder(handle_unknown="ignore", sparse_output=False)`.

#### 📊 Підсумкова порівняльна таблиця кандидатів (Крос-валідація на Train)
Усі параметри та алгоритми порівнювалися виключно за середніми метриками на крос-валідації:

| Модель | Найкращі параметри за CV | CV F1 середнє | CV F1 std | CV Recall | CV ROC AUC |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **Logistic Regression** | **penalty='l2', C=0.1, solver='saga'** | **0.8415** | 0.032 | 0.8120 | 0.9012 |
| **SVM (RBF-ядро)** | kernel='rbf', C=1, gamma='scale' | 0.8390 | 0.029 | 0.8040 | 0.8985 |
| **LDA** | default | 0.8245 | 0.035 | 0.7950 | 0.8940 |
| **k-NN** | n_neighbors=7, metric='euclidean' | 0.8120 | 0.041 | 0.7730 | 0.8650 |
| **GaussianNB** | default | 0.8010 | 0.045 | 0.8310 | 0.8820 |
| **QDA** | reg_param=0.1 | 0.7850 | 0.052 | 0.7420 | 0.8510 |

#### 🔒 Фінальне тестування та збереження моделі
За критерієм найкращого CV F1 як фінальну модель до відкриття тесту було зафіксовано **Логістичну регресію**. Конвеєр було навчено на всьому Train-наборі та один раз оцінено на відкладеному Test.

* **Результати на Test:** F1-Score = **0.9180** | ROC AUC = **0.9630** | Accuracy = **0.9259**.
* **Аналіз матриці помилок:** На тестових даних модель припустилася лише **8 помилок** (5 False Positives та 3 False Negatives), що демонструє чудову узагальнювальну здатність і відсутність перенавчання.
* **Інтерпретація:** Топ-3 найважливіших ознак за модулем коефіцієнтів лог-регресії: кількість великих судин (`ca`), тип болю в грудях (`cp`) та максимальний пульс (`thalach`).
* **Додаткова частина:** Досліджено поліноміальне ядро SVM; проведено аналіз калібрування ймовірностей (Reliability Diagram), який підтвердив високу точність прогнозованих частот лог-регресії порівняно з GaussianNB.
* Фінальний працездатний конвеєр серіалізовано в `models/best_classifier.joblib`.
